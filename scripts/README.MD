## Счётчик лайков
- ищет карточку с лайками, при клике прибавляет или уменьшает

## Открытие/Закрытие, перемещение формы
- Форма открывается при нажатии на кнопку
- Форма закрывается при нажатии на крестик или за форму
- Есть возможность переместиться из формы авторизации в форму регистрации и обратно

## Регистрация пользователя
Проверяет:
1. Существует ли уже логин,
2. Пароль содержит больше 8 символов,
3. Совпадения паролей,
4. Пароль совпадает с логином.

## Хранение данных
- Массив 'Person' проверяет всех зарегистрированных пользователей
- 'currentPerson' хранит логин вошедшего пользователя
- Автозаполнение логина при загрузке
