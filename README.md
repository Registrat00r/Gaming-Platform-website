# Задание 2

- Добавленна адаптация от 1400px до 600px
- Добавленна анимация текста, с помощью hover (при наведении)

# Задание 3

- Добавленна форма Входа
- Форма сделана спомощью спомогательных элементов
- При нажатии на кнопку "Sign up" открывается форма входа
- При нажатии на крестик форма закрывается
- При нажатии за форму форма закрывается
- При открытии формы блокируется движение, при закрывании движении разблокируется
- Добавлен счётчик лайков
- При клике на огонёк, число или надпись прибавляется лайк, при повторном нажатии убирается
- Добавленна форма Авторизации пользователя
- При нажатии на "Зарегестрироваться" в форме "Входа" открывается форма авторизации
